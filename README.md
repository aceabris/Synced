# SYNCED — ITSO Election Campaign Website

A modern, interactive campaign website developed for the **SYNCED Partylist** during the **Information Technology Student Organization (ITSO) Elections S.Y. 2026–2027**.

The website showcases the party's candidates, platforms, and proposed projects through an engaging, responsive, and animated user experience.

---

## 📖 Overview

SYNCED aims to present its vision through a clean and modern digital platform inspired by software development principles.

The campaign framework is built around three core concepts:

* **REFACTOR** – Streamlining student services and processes.
* **DEPLOY** – Launching impactful academic programs and student initiatives.
* **DEBUG** – Listening to student concerns and implementing meaningful solutions.

---

## ✨ Features

* Responsive design for desktop and mobile devices
* Interactive splash screen
* Animated navigation menu
* Candidate showcase
* Platform presentation
* Project roadmap
* Candidate detail modal
* Image viewer with flip animation
* Scroll progress indicator
* Modern UI inspired by software development

---
